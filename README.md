# Objektově orientovaný nákupní seznam
## Konzolová aplikace
## Popis
Předělání nákupního seznamu na objektově orientovaný přístup, aplikace čte a ukládá do textového souboru položky nákupu.
## funkce
- Přidávání nákupních položek do seznamu.
- Vypsání všech položek v nákupu.
- Vypsání celkové ceny v nákupu.
- Vypsání nejdražší položky v nákupu.
## jak program spustit ?
Ke spuštění musí být nainstalovaný python 3. poté se dá program spustit double clickem, nebo v terminálu pomocí příkazu python Nakup.py
